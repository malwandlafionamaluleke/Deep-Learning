# Deep Learning

This repository showcases deep learning projects that apply neural networks to solve complex engineering, computer vision and data science problems.

---

## Repository Overview

The projects in this repository demonstrate the design, training and evaluation of deep learning models for image classification, sequence modelling, anomaly detection and representation learning.

The portfolio focuses on building scalable and interpretable deep learning solutions using modern frameworks and best practices.

---

## Areas Covered

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Long Short-Term Memory Networks (LSTM)
- Gated Recurrent Units (GRU)
- Transformer Models
- Autoencoders
- Variational Autoencoders (VAE)
- Transfer Learning
- Representation Learning
- Model Optimisation
- Explainable AI
