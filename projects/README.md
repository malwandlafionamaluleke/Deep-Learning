# Projects

This directory contains end-to-end deep learning projects demonstrating the application of neural networks to engineering, manufacturing, logistics and computer vision challenges.

## Project Categories

- Image Classification
- Computer Vision
- Object Detection
- Image Segmentation
- Activity Recognition
- Sequence Modelling
- Time Series Analysis
- Transfer Learning
- Representation Learning
- Explainable AI

Each project includes the problem statement, dataset, model architecture, training process, evaluation metrics and deployment considerations.
